# Repository conventions for Claude Code

## Attribution

- **Never** add `Co-Authored-By: Claude …` (or any other AI co-author) trailers to commit messages.
- **Never** mention Claude, Claude Code, or any AI assistant in PR titles, bodies, or footers — no "Generated with Claude Code" line, no 🤖 emoji footer.
- Commits and PRs should read as the author's own work.
